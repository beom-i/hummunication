# 주보 UI 재점검

기준: `main`의 `c095d1c` (PR #12, #13 병합 후). 이전 캡처 보고서의 번호를 유지한다.

| 번호 | 최신 main 상태 | 이번 변경 |
| --- | --- | --- |
| 1 날짜 입력 | 파송 날짜도 공통 DatePicker 사용, 지우기 포함 | 중복 수정 없음 |
| 2 새가족 입력 화면 | FamilyEditor로 통합, 예전 URL도 같은 화면으로 연결 | 변경 없음 |
| 3 중복 편집 버튼 | 카드별 편집 화면·버튼 제거, 순 목록에서 편집 | 변경 없음 |
| 4 공통 표지 | 결과·다운로드에서 순마다 동일 표지 생성 | 공통 표지 한 장만 생성, 순별 썸네일·문답 유지 |
| 5 미리보기 스크롤 | 폼과 함께 스크롤되어 사라짐 | PC 고정, 모바일·태블릿 위쪽 작은 미리보기 고정 및 클릭 확대 |
| 6 저장 안내 | 브라우저 보관 문구와 서버 저장 버튼 구분 | 변경 없음 |
| 7 파송자 여러 장 | 카드 페이지 이동 지원, 같은 사람 유지 | 변경 없음 |
| 8 발행일 | 2026년 11월 목업 날짜 고정 | 한국 날짜 기준 가까운 네 주일, 새 작업 날짜도 첫 주일로 시작 |
| 9 파송자 관리 정보 | 소속 순·날짜를 저장하지만 카드에는 미표시 | 폼에 관리용 안내와 접근성 설명 연결, 카드 디자인 유지 |

기존 드래프트의 선택 날짜는 새 주일 목록 밖에 있어도 유지한다. 기존 주보 편집의 발행일 고정도 유지한다. 원본 데이터·DB·API·사진 편집 방식은 변경하지 않는다.
