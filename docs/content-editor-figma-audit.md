## 아직 원본과 같다고 할 수 없는 부분

- **편집 패널 폭:** 원본 새가족/파송자 폼은 560px, 현재 공통 입력 열은 380px이다. 미리보기 최대 폭도 원본 360px과 현재 300px이 다르다. 공통 레이아웃 적용 결과이며, 입력 줄바꿈과 사진 표시 크기는 원본 화면과 일치하지 않는다.
- **사진 제한:** 현재 PNG/JPG/WebP 입력 상한은 5MB이며, 모달은 원본/권장/더 작게를 제공한다. 모든 업로드를 자동으로 2MB 이하로 만드는 보장은 구현되어 있지 않다. 이번 변경에서 제한 문구만 2MB로 바꾸지 않았다.
- **파송자 부가 정보:** 소속 순/파송 날짜는 저장되지만 현재 카드 템플릿에는 출력되지 않는다. 입력/저장 성공과 카드 출력은 별도 동작이다.
- **이번 대조 밖:** 홈·온보딩·전체 템플릿의 모든 픽셀을 이번 작업에서 다시 검증하지 않았다. 발행 날짜 선택의 2026년 11월 고정 목록은 기존 제약으로 남아 있다.

## 템플릿 최종 대조 · 246:4302

`246:4302` 페이지 아래의 원본 13개 프레임을 최신 Figma에서 다시 내려받아, 같은 데이터로 앱에서 실제 내려받은 PNG와 50% 겹쳐보기 및 투명도 조절로 비교한다. 원본은 썸네일 720×514, 나머지 12장 720×900이다. 웹의 갤러리 프레임과 파일 자체의 비율은 별개이며, 이번 프레임 보정으로 파일 크기를 바꾸지 않았다.

- 설교/기도문은 원본 줄바꿈·문단 좌표·실제로 사용한 Pretendard 폰트를 기존 브라우저 회귀 검사로 확인한다. 문구가 같은 것과 서식·줄바꿈이 같은 것을 구분한다.
- 사진 기본 크롭이 90%여서 적용만 해도 확대되던 원인을 수정했다. 신규 사진은 지정 비율에서 최대 영역을 담으며, 기존에 저장한 크롭은 유지한다. 같은 비율의 사진은 전체 영역으로 시작하는 회귀 검사를 추가했다.
- 새가족 썸네일 이름 구분은 공백 문자열 조합 대신 원본과 같은 3px 간격으로 렌더링한다.
- 비교 사진의 원본 PNG가 9MB 이상이라 업로드 제한을 넘는다. 임시 비교 자료에서만 무손실 WebP로 변환했으며, 디코딩한 RGB 픽셀 일치를 확인했다. 앱의 실제 파일 선택/크롭/적용 경로로 입력했다. 사진과 Figma 예시 인물 데이터는 저장소에 추가하지 않는다.
- 최종 겹쳐보기, 실제 PNG ZIP과 측정값은 `/tmp/hummunication-final/report/`에 생성한다. 렌더러별 글꼴 가장자리의 미세한 래스터 차이를 픽셀 완전 일치로 표현하지 않는다.
